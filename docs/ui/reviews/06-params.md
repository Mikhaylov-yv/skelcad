# Ревью: экран «Параметры» с черновиком (шаг 6 M2, D17)

Дата: 2026-10-19. Экран: `/p/<project>/<variant>/params` — форма из `project.params` и
`variants/<v>.yaml` (поле помечено «общий» или «вариант»), «Собрать черновик» (сборка во
временном снимке без коммита), дельты и 3D-наложение «было / черновик», «Сохранить» с
сообщением — коммит от имени конструктора, артефакты черновика становятся текущими.
Скриншот: `06-params.png`. Чеклист — `docs/ui/checklist.md`.

1. Видимость состояния — ок: изменённые поля подсвечены и подписаны «было 120»; «Собираю черновик… N с (лимит 180 с)»; «Черновик собран…» / «Параметры изменились после сборки черновика — соберите заново» (черновик привязан к набору изменений).
2. Соответствие реальному миру — ок: имена параметров как в файлах проекта (их же читает агент), группы по узлам (`base_plate`, `welds`, `members`); сообщение коммита по умолчанию «members.gap 120 → 140» в принятом формате.
3. Свобода и контроль — ок: черновик не трогает проект; «Сбросить» возвращает значения; сохранение только явной кнопкой с сообщением; результат — обычный коммит, откатываемый в ленте.
4. Единообразие — ок: та же строка чисел и дельт, то же наложение (синий — было, красный — стало), те же виды.
5. Предотвращение ошибок — ок: «Нужно число» и предупреждение об отрицательном значении до сборки; «Собрать черновик» закрыта без изменений или при ошибке; «Сохранить» закрыта, пока черновик не собран для текущих значений или пустое сообщение. Проблема: диапазонов в модели нет (схема `params` — свободный объект) → хвост: диапазоны и единицы из схемы генератора.
6. Распознавание — ок: значения и источники видны, не нужно помнить структуру YAML; комментарии в файле варианта сохраняются при правке.
7. Гибкость — ок: тот же файл правит агент через `files_write`; черновик кэшируется по набору изменений.
8. Минимализм — ок: две колонки — форма и результат; служебных деталей (пути файлов, hash) нет.
9. Исправление ошибок — ок: ошибка сборки черновика (например, генератор упал на новом значении) показывается текстом сервера под формой, проект не меняется.
10. Помощь — ок: подсказка в шапке объясняет, откуда значения и куда сохраняются; плейсхолдер сообщения даёт пример.

Пороги: форма и результат на 1366×768 без прокрутки для bracket (11 полей, `06-params.png`); черновик bracket — ~5–40 с (воркер).
Найдено и исправлено по ходу: относительный `SKELCAD_DATA` ломал запись файлов (путь вне корня) → корень workspace теперь резолвится.
