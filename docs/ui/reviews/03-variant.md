# Ревью: экран «Вариант» (шаг 3 M2)

Дата: 2026-10-19. Экран: `/p/<project>/<variant>` — дерево (детали, швы, крепёж, прочее), 3D
(GLB, подсветка, затенение остального, разрез по X/Y/Z, виды главный/слева/сверху/изометрия,
«Вписать»), панель чисел, замечаний, запасов K, производных размеров и допущений.
Скриншоты: `03-variant-weld.png` (замечание про шов → подсвечены плита и щека),
`03-variant-clip.png` (главный вид с разрезом по X). Чеклист — `docs/ui/checklist.md`.

1. Видимость состояния — ок: в шапке «собрано N мин назад», «Сборка идёт… N с (лимит 180 с)» при пересборке, «Загружаю 3D…» до загрузки модели, «Снять выделение (2)» показывает, сколько узлов выделено.
2. Соответствие реальному миру — ок: детали названы как в модели («Плита опорная δ16 270×290»), массы в кг, швы «к8 · 200 мм», виды по ЕСКД, K с требуемым значением рядом; Z вверх, как в модели и SVG-видах (glTF-поворот Y-вверх компенсирован).
3. Свобода и контроль — ок: любое выделение снимается кликом в пустоту или кнопкой; разрез и затенение — переключатели; экран ничего не меняет в проекте без явной «Собрать заново».
4. Единообразие — ок: та же строка чисел, что на «Проектах»; цвета уровней общие; ссылки замечаний (`weld:w_cheek_L_in`) одинаковы в UI и в ответах MCP, агент и конструктор говорят об одном.
5. Предотвращение ошибок — ок: кнопка сборки блокируется на время сборки (`aria-busy`); несобранный вариант объясняется, а не падает.
6. Распознавание — ок: клик по замечанию или строке K подсвечивает элемент в 3D и в дереве; клик по модели выделяет узел; `?part=` в адресе для ссылок из чата агента. Проблема → решено: 27 справочных замечаний спрятаны за «Показать», чтобы 3 предупреждения были видны без прокрутки.
7. Гибкость — ок: всё кнопками (клавиатура), глубокие ссылки, тот же `report.json` доступен агенту через `build`/`check`.
8. Минимализм — ок: три области, в шапке только числа и две кнопки; hash и пути файлов не показываются.
9. Исправление ошибок — ок: ошибка сборки показывается текстом из сервера (`role=alert`); сбой 3D ловится границей ошибок с подсказкой про WebGL; нет сети — «Повторить». Улучшение позже: хвост лога воркера и «Откатить последний коммит» (шаг 4).
10. Помощь — ок: у замечания код правила и источник (`R-WELD-ACCESS · rules.gost`), формула расчёта во всплывающей подсказке строки K, допущения с id (G1…) раскрываются.

Пороги: вариант `A_fork` отрисовывается за ~1 с на LAN (GLB 300 кБ); экран 1366×768 — числа, предупреждения и 3D без прокрутки (см. скриншоты). Найденные и исправленные по ходу дефекты: GLB в метрах (камера отсекала модель ближней плоскостью) → масштаб ×1000; Y-вверх glTF → поворот; `<Html>` из drei в fallback Suspense ломал React-дерево → убран.
