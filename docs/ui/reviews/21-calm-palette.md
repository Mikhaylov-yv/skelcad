# Ревью: спокойная палитра (M2.4, D31)

Дата: 2026-10-21. Экраны: «Проекты», «Лента», «Вариант», «Сравнение», «Подключение агента» — общие стили
(`web/src/index.css`). Повод — замечание конструктора: «интерфейс перегруженный и пёстрый, разные вещи отвлекают
внимание, с первого взгляда теряется желание разбираться». Было (`21-projects-before.png`, `21-feed-before.png`):
пять цветов на экране (синий ссылок, фиолетовый агента, красный, оранжевый, зелёный), красные «Откатить» на каждой
карточке ленты, цветные полосы слева у коммитов, подписи чисел капителью в каждой строке варианта, «Стандарты: gost»
отдельной строкой, подвал карточки не влезал в ширину. Стало (`21-projects.png`, `21-feed.png`): один акцент; цвет
только там, где нужно решение (красный — ошибки, янтарный — «не согласована», «изменена после согласования»,
непросмотренные, предупреждения); автор-агент без цвета; коммиты без полос; «Откатить» — обычная кнопка, красная
только в диалоге подтверждения; «ок»-плашки нейтральные; на карточке проекта таблица вариантов с шапкой один раз
и названием варианта под кодом, стандарты в строке кода, ссылки подвала переносом; лучший в сравнении — тон
акцента; замечание на варианте — тонкая линия вместо жёлтой полосы; заголовки разделов приглушены; одна залитая
кнопка на экран (`button.primary` — «Запустить»). Чеклист — `docs/ui/checklist.md`.

1. Видимость состояния — ок: состояния остались («у агента» — акцентная плашка с заливкой, «выполняется» —
   пульсирующая точка), но перестали спорить друг с другом.
2. Соответствие реальному миру — ок: цвет = светофор решений: красное блокирует, янтарное ждёт решения, остальное
   рабочее; слова те же.
3. Свобода и контроль — ок: откат доступен там же, подтверждение в диалоге с красной кнопкой — там, где действие
   необратимо без нового коммита.
4. Единообразие — ок: плашки `badge` / `pill` / `state` на одних токенах (`--accent-soft`, `--warning-soft`,
   `--error-soft`); таблица вариантов на карточке читается так же, как таблица сравнения.
5. Предотвращение ошибок — ок: красного стало меньше, поэтому ошибка (K min 1,14, «ошибок 1») заметнее, а не
   теряется среди красных кнопок.
6. Распознавание — ок: название варианта под кодом в той же ячейке; шапка таблицы объясняет столбцы один раз.
7. Гибкость — ок: тёмная тема получила те же мягкие токены; ничего не завязано на наведение.
8. Минимализм — ок: с карточки проекта ушли строка стандартов, капительные подписи в каждой строке, зелёная плашка
   «согласована» (норма не подсвечивается); ссылки подвала переносятся, «Агент» больше не обрезан.
9. Исправление ошибок — ок: тексты ошибок остались красными и первыми.
10. Помощь — ок: пустые состояния и подсказки на месте, подсказки формы свёрнуты, а не удалены.

Что не трогали: экран «Вариант» структурно (три области, вкладки, панели) — хвост в плане M2.4; блок «Как работать»
на «Проектах».
