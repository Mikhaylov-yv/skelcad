# Ревью: вход и шапка (шаг 2 M2)

Дата: 2026-10-19. Экран: вход через Keycloak (oauth2-proxy, realm `home`), имя пользователя и
«Выйти» в шапке, коммиты из workbench от имени пользователя. Чеклист — `docs/ui/checklist.md`.

1. Видимость состояния — ок: в шапке видно, кто вошёл (имя, почта во всплывающей подсказке); без входа браузер сразу уходит на страницу Keycloak, промежуточных экранов нет (`SKIP_PROVIDER_BUTTON`).
2. Соответствие реальному миру — ок: пользователь входит той же учётной записью, что в остальные домашние сервисы; слово «Выйти», не «sign out».
3. Свобода и контроль — ок: «Выйти» возвращает на `https://skelcad.br`, откуда можно войти снова.
4. Единообразие — ок: та же схема входа, что у drawio.br и excalidash.br; агент по-прежнему по токену, его коммиты подписаны «агент (клиент)», коммиты человека — его именем.
5. Предотвращение ошибок — ок: `/out`, `/api` и `/` закрыты за входом; `/mcp` вычищает пользовательские заголовки, подсунуть чужое имя мимо входа нельзя.
6. Распознавание — ок (нечего запоминать: вход один раз на неделю, cookie 168 ч).
7. Гибкость — ок: CLI и агенты ходят в `/api` по Bearer-токену без браузера.
8. Минимализм — ок: шапка = название, разделы, имя, «Выйти».
9. Исправление ошибок — ок частично: 401 от API показывается словами «нужен вход»; истёкшая сессия приводит к редиректу на Keycloak при следующем переходе, а в открытом экране — к ошибке с кнопкой «Повторить» → при повторе редирект. Улучшение (позже): перехватывать 401/302 в клиенте и предлагать «Войти заново».
10. Помощь — ок: описание входа в README и `docs/guide-workbench.md` (шаг 9).
