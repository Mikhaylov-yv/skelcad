# Ревью: экран «Задача агенту» (шаг 8 M2, D16)

Дата: 2026-10-19. Экран: `/p/<project>/agent` — текст задачи, вариант, «Запустить»; список
задач со статусами; ход выбранной задачи (вызовы инструментов, ответы, отчёт) с опросом раз в
2 с; «Остановить». Пока задача в очереди или выполняется, проект «у агента»: на экранах
варианта, параметров и ленты — полоса с объяснением, правки закрыты (D6). Исполнитель —
контейнер `agent` (`skelcad agent --queue`): цикл с любым провайдером по OpenAI-совместимому API
или headless Claude Code. Скриншоты: `08-agent-running.png`, `08-agent-locked.png`.
Чеклист — `docs/ui/checklist.md`.

1. Видимость состояния — ок: статус задачи («в очереди / выполняется / выполнена / ошибка / остановлена / лимит шагов»), «шагов N из 60», кто поставил, живой лог вызовов; на других экранах — полоса «Проект у агента: задача … · выполняется». Если контейнер агента не запущен — подсказка, почему задача остаётся «в очереди».
2. Соответствие реальному миру — ок: задача формулируется словами конструктора, подсказка с примером; в логе — «вызов project_read {…}», «агент: …», «Отчёт агента».
3. Свобода и контроль — ок: «Остановить» в любой момент (флаг стоп проверяется между шагами, у Claude Code — завершение процесса); результат работы агента — обычные коммиты, откатываемые в ленте.
4. Единообразие — ок: те же статусные бейджи и цвета, что у коммитов; ссылка «Смотреть изменения в ленте» после завершения.
5. Предотвращение ошибок — ок: вторая задача на тот же проект не ставится (409 «проект уже у агента»); кнопки правок закрыты и объяснены; лимит шагов на сервере, не в задаче.
6. Распознавание — ок: выбор варианта из списка; текст задачи сохраняется в истории задач.
7. Гибкость — ок: провайдер модели меняется настройкой сервера (`LLM_BASE_URL`, `LLM_MODEL`, ключ в секрете), исполнитель `claude-code` для подписки; агент из терминала конструктора работает параллельно по тем же инструментам.
8. Минимализм — ок: форма слева, лог справа; результаты инструментов показываются сводкой, не JSON.
9. Исправление ошибок — ок: ошибка провайдера или моста MCP попадает в лог как «Ошибка: …» и в статус задачи; задача не висит.
10. Помощь — ок: подсказка над формой объясняет, что агент сделает и что всё обратимо.

Проверка живьём: задача на локальном сервере «ответить на открытые замечания конструктора» —
исполнитель claude-code, агент прочитал review_list, измерил зазор и закрыл R1 ответом
(см. ленту проекта: коммит «ответ на R1: …»); экран параметров на время задачи закрыт
(`08-agent-locked.png`).
