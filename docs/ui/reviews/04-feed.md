# Ревью: экран «Лента» (шаг 4 M2)

Дата: 2026-10-19. Экран: `/p/<project>/commits?variant=<v>` — коммиты сверху вниз, карточка:
автор (агент / конструктор / система / откат), время, сообщение, файлы; «Разница» (строка
дельт, изменённые сущности, ушедшие и новые замечания, 3D-наложение «было/стало»),
«Просмотрено» (заметка git с именем), «Откатить» (диалог с предпросмотром). Счётчик
непросмотренных изменений агента в шапке и на карточке проекта. Скриншоты:
`04-feed-diff.png`, `04-feed-3d.png`, `04-feed-revert.png`. Чеклист — `docs/ui/checklist.md`.

1. Видимость состояния — ок: «текущее состояние» на HEAD, «непросмотренных изменений агента: N», «Считаю разницу… обычно 10–60 с», «Строю геометрию прошлого состояния… до 180 с», «Откатываю…».
2. Соответствие реальному миру — ок: «агент (claude-code)», «конструктор», «откат»; дельты «15,33 → 15,63 кг (+0,3)», «K min 1,14 → 1,54 (+0,4)», «предупреждений −1»; 3D в идиоме Onshape: синий — было, красный — стало, серый — без изменений, ползунок «было ↔ стало».
3. Свобода и контроль — ок: откат — новый коммит (откат отката возможен, так и написано в диалоге); «Отмена» закрывает диалог без последствий; «Просмотрено» снимается; разница и 3D сворачиваются.
4. Единообразие — ок: та же строка чисел (`NumbersRow`/`DeltaRow`), те же виды (главный/слева/сверху/изометрия), те же цвета уровней; «Лента» доступна с карточки проекта и с экрана варианта.
5. Предотвращение ошибок — ок: откат только через диалог с сообщением, автором, файлами и дельтами; системный коммит откатить нельзя; выдача STEP на экране варианта закрыта при error (шлюз). Проблема → решено: при ошибке отката (конфликт) текст сервера остаётся в диалоге, коммит не создаётся (`git revert --abort`).
6. Распознавание — ок: сущности и замечания названы теми же id, что в MCP; hash короткий справа, полный во всплывающей подсказке; нет нужды помнить, что менялось — дельты считаются по модели и сводке.
7. Гибкость — ок: разница и геометрия прошлых состояний кэшируются в `out/<p>/_commits/<hash>/`, второй показ мгновенный; ссылка на ленту с вариантом `?variant=`.
8. Минимализм — ок: карточка без разницы — четыре строки; справочные замечания в дельтах не считаются; служебные сущности (`units`, `derived`) показаны одной строкой.
9. Исправление ошибок — ок: ошибки сервера показываются словами в карточке (`role=alert`); упавшая сборка снимка не ломает ленту.
10. Помощь — ок: текст в диалоге объясняет, что такое откат; легенда цветов под ползунком.

Пороги: решение по карточке — сообщение, дельты и ушедшие замечания видны без прокрутки на 1366×768 (`04-feed-diff.png`); 3D-наложение по запросу, первый показ ждёт сборку прошлого состояния (~30–60 с на bracket), дальше из кэша.
