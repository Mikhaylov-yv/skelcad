# Ревью: «Выдача» и «Подключение агента» (шаг 9 M2)

Дата: 2026-10-19. Экраны: меню «Выдача» на экране варианта (STEP сборки, glTF, SVG-виды,
отчёт JSON; при ошибках — закрыто с объяснением); `/tokens` — токены клиентов MCP для
администраторов (группа `admins`): выдать, увидеть команду `claude mcp add …` один раз,
отозвать. Чеклист — `docs/ui/checklist.md`.

1. Видимость состояния — ок: «Выдача закрыта: ошибок N» вместо меню; у токена — кто и когда выдал, «из настроек сервера» для статических.
2. Соответствие реальному миру — ок: «комплект», «STEP сборки», «вид слева»; «выдать / отозвать токен», а не «create / revoke».
3. Свобода и контроль — ок: отзыв только через подтверждение; меню выдачи — `details`, закрывается кликом.
4. Единообразие — ок: та же точка MCP и та же команда, что в README и AGENTS.md; коммиты нового клиента подписываются его именем, как у остальных.
5. Предотвращение ошибок — ок: имя клиента проверяется (строчные латинские, без пробелов), повтор имени отклоняется, не-администратору форма не показывается и сервер отвечает 403; выдача при error закрыта.
6. Распознавание — ок: готовая команда для копирования, не нужно собирать её вручную.
7. Гибкость — ок: статические токены из `SKELCAD_TOKENS` продолжают работать; новые — в `tokens.json` на сервере, подхватываются без перезапуска.
8. Минимализм — ок: одна форма, один список.
9. Исправление ошибок — ок: ошибки сервера показываются словами (`role=alert`).
10. Помощь — ок: подсказка объясняет, что токен показывается один раз и зачем имя клиента.
