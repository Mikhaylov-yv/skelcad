# Ревью: провайдеры модели встроенного агента (D29)

Дата: 2026-10-21. Экран: «Подключение агента» (`/tokens`), раздел «Провайдеры модели» — список провайдеров
(название, код, адрес API и модель, «ключ задан (…1234)» или «ключ не задан», кто и когда менял, отметка «по
умолчанию»), кнопки «Проверить», «По умолчанию», «Изменить», «Удалить» (администратор); форма: шаблон (OpenRouter,
OpenAI, DeepSeek, Ollama, LiteLLM, свой адрес), код, название, вид (OpenAI-совместимый API или Claude Code по
подписке), адрес API, ключ (поле-пароль; при правке пусто = не менять), модель по умолчанию с подсказкой из
«Получить список моделей» (цены за 1M токенов, если провайдер отдаёт), «Проверить» коротким запросом (модель,
время, стоимость, ответ). Экран «Агент»: у задачи выбор провайдера («по умолчанию (…)» или любой) и модели
(подсказка из списка провайдера); в ходе задачи — провайдер, модель, токены и стоимость. Скриншоты:
`18-providers.png`, `18-providers-test-error.png`, `18-agent-provider.png`. Чеклист — `docs/ui/checklist.md`.

1. Видимость состояния — ок: видно, какой провайдер по умолчанию, задан ли ключ (хвост), кто менял; «Запрашиваю…»,
   «Проверяю…», «Сохраняю…» на кнопках; результат проверки — строкой «ответила <модель> за N с, стоимость … $»;
   без `SKELCAD_SECRET_KEY` — красное предупреждение «ключи хранятся без шифрования».
2. Соответствие реальному миру — ок: термины провайдеров (base_url, модель, ключ API), шаблоны с готовыми адресами,
   цены в $ за 1M токенов как на сайтах провайдеров; Claude Code назван «подписка, без ключа».
3. Свобода и контроль — ок: «Отмена» в форме; ключ при правке можно не трогать; удаление с подтверждением и словами
   «ключ будет стёрт с сервера»; смена умолчания одной кнопкой; задача может выбрать другого провайдера разово.
4. Единообразие — ок: та же форма-карточка и ссылки-кнопки, что у токенов и замечаний; те же статусы «Сохранено».
5. Предотвращение ошибок — ок: ключ никогда не возвращается с сервера (только хвост); код провайдера валидируется
   словами; адрес API проверяется на `http(s)://`; список моделей и проверка — до сохранения, с ключом из формы;
   правки закрыты не администраторам (403 и подпись).
6. Распознавание — ок: шаблоны вместо ввода адресов; подсказка моделей с ценами; задача показывает модель по
   умолчанию в подсказке поля.
7. Гибкость — ок: несколько провайдеров и моделей, выбор в задаче; API `/api/providers*`; старый путь через
   переменные окружения и секрет Gitea остаётся запасным.
8. Минимализм — ок: форма появляется по кнопке; в списке три строки на провайдера.
9. Исправление ошибок — ок: ответ провайдера приходит словами («провайдер ответил 401 — ключ не принят: …»,
   «404 — проверьте base_url (обычно заканчивается на /v1) и имя модели»), форма остаётся заполненной.
10. Помощь — ок: подсказка раздела объясняет, где хранится ключ и как выбирается провайдер.

Проверка живьём: dev-сервер без `SKELCAD_SECRET_KEY` — добавлен OpenRouter по шаблону с ключом-пустышкой (файл
`providers.json` с правами 0600, ключ не в ответах API), «Проверить» → «провайдер ответил 401 — ключ не принят»;
добавлен Claude Code и отмечен по умолчанию; на экране «Агент» селектор «по умолчанию (Claude Code (подписка))»,
при выборе OpenRouter появляется поле модели с подсказкой `anthropic/claude-sonnet-4.5`; ошибок страницы нет.
Проверка с настоящим ключом OpenRouter — за конструктором (ключ вводится на экране).
