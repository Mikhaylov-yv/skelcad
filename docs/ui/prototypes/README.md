# Макеты рабочего места (M2.5, переосмысление с чистого листа)

Четыре самостоятельных HTML-макета рабочего места конструктора на одной модели данных: папки и проекты
(те, что лежат на сервере — «Болт обычный М16», «Специальный болт» — и примеры), четыре этапа изделия
(задание → компоновка → конструкция → комплект), единственный «следующий шаг», имитация работы агента
фразами и картинками, отмена действий. Повод — замечание конструктора 2026-10-21: интерфейс перегружен,
главная страница должна быть деревом папок, непонятно, что делать после согласования компоновки, нужно
больше графики и меньше текста (план `docs/architecture/10-m2-5-workbench-plan.md`).

- `index.html` — сравнение: сводная таблица, скриншоты, заметки. Открывать как файл.
- `v01-explorer.html` — «Проводник»: дерево слева, этапы плитками, агент справа.
- `v02-timeline.html` — «Лента проекта»: проект одной страницей сверху вниз по этапам.
- `v03-desk.html` — «Рабочий стол»: картинка во весь экран, этапы в шапке, справа «Сейчас».
- `v04-board.html` — «Доска»: этапы столбцами; в папке матрица проекты × этапы.
- `core.js` — модель: данные, этапы и правила «следующего шага», имитация агента (`SCRIPTS`), отмена, общие
  кусочки (дерево, карточка «что дальше», ход агента, карточка варианта, окна). `core.css` — палитра D31.
- `img/` — картинки: изометрии и эскизы примеров (`uv run skelcad build`), компоновочные эскизы, набросок
  конструктора, рисованные схемы болтов (SVG).
- `run.mjs` + `variants.json` — прогон одинаковых сценариев конструктора Playwright'ом (из `web/node_modules`):
  `node run.mjs [фильтр]` → `results.json`, скриншоты в `shots/`; затем `python3 compare.py` → `index.html`.
- `picks.json` — какой макет предложен за основу и почему.

Сценарии прогона (10): открыть проект из дерева; понять, что дальше, и поручить агенту детали; согласовать
компоновку; выбрать вариант; выдать комплект; скачать комплект; создать проект в папке; описать задание и
получить компоновку; создать папку; удалить проект и вернуть. Действия считает прогон: щелчок, клавиша = 1,
ввод текста = 2.
