## Что агент прочитал и что записал

Прочитано с наброска (из отчёта агента и G1): стена слева → база `wall` и тело `wall_body`; плита s=12 высотой
300; 4 анкера M16; два ребра, сужаются к трубе; труба Ø108, ось на 500 от стены; Fv = 20 кН вниз.

| Величина | Значение | Откуда |
|---|---|---|
| Вылет оси трубы от стены | 500 | подписано |
| Высота плиты | 300 | подписано |
| Толщина плиты | 12 | подписано |
| Анкеры | 4 × M16 | подписано |
| Диаметр трубы | 108 | подписано |
| Fv | 20 кН | подписано |
| Fh, Fa | 0 | не показаны → допущение G2 |
| Ширина плиты по X | 200 | оценка → G4 |
| Шаг анкеров X × Z | 120 × 220 | по пропорциям → G4 |
| Высота рёбер у стены / у трубы | 220 / 140 | по пропорциям → G5 |
| Ось трубы по высоте | середина плиты | по пропорциям → G3 |
| Стена | бетон B25, ≥ 250 | допущение G6 (hef анкера M16 по каталогу) |
| Труба | 108×6 | ближайшая в сортаменте gost → G7 |

Коммиты агента: `456fc95` пакет стандартов gost и название; `7ebabbe` требования, скелет (базы `wall`,
`pipe_axis`; интерфейсы `wall` mount_plane с 4 анкерами M16, `pipe` pipe_rest Ø108; зона `place`), обстановка
(`wall_body` plane, `pipe_body` cylinder), допущения G1–G9; `d8efea3` поля цилиндра приведены к схеме
(`center`, `diameter` вместо `origin`, `d`) — первая запись не прошла валидацию, компоновка не строилась.
Результат — `m2-3-sketch-pilot/project.yaml`, компоновка `layout_main.png`, `layout_left.png`: стена слева,
ось трубы на 500 (размер `wall-pipe_axis` = 500), труба Ø108, зона кронштейна, нагрузка Fv вниз на оси трубы.
Агент остановился до согласования и перечислил, что просит подтвердить (горизонтальные нагрузки, ширина плиты,
длина ложемента, труба без хомута).
